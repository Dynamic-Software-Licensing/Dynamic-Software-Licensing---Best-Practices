# 04.05. Abbreviations

## Purpose

This section defines the recurring abbreviations used throughout the Dynamic Software Licensing (DSL) best practices repository.

## Scope Statement

This section provides a concise reference for abbreviated terms that cross technical, operational, and commercial boundaries. These abbreviations should be interpreted consistently across all chapters and annexes.

## Definitions

| Abbreviation | Full Term | Definition / Context within DSL |
| :--- | :--- | :--- |
| **CapEx** | Capital Expenditure | Traditional, static financial models where hardware and perpetual software licenses are bought upfront as long-lived assets. |
| **DR** | Disaster Recovery | High-availability failover configurations requiring rapid, automated license mobility without manual vendor intervention. |
| **DSL** | Dynamic Software Licensing | The core initiative and architectural framework defined by this document. |
| **HA** | High Availability | Architectural designs optimized for continuous production uptime, necessitating resilient, non-blocking license validation. |
| **IaC** | Infrastructure as Code | The practice of provisioning and managing infrastructure using configuration files (e.g., Terraform), into which DSL must natively integrate. |
| **ISV** | Independent Software Vendor | Software manufacturers and publishers who develop, license, and support broadcast and media products. |
| **JWKS** | JSON Web Key Set | A cryptographic standard contract used by the Workspace Plane to discover public keys and validate signed license tokens. |
| **OpEx** | Operational Expenditure | Pay-as-you-go financial models matching consumption metrics, flexible workflows, and dynamic software-defined deployments. |
| **SI** | System Integrator | Third-party organizations responsible for designing, deploying, and operationalizing multi-vendor architectures for media clients. |
| **SRE** | Site Reliability Engineer | The platform-level operational persona focused on runtime uptime, failure-domain containment, and system recovery. |
