# 02. Current Licensing Challenges

## Purpose

This subchapter identifies the concrete problems and friction points that organizations across the broadcast and media industry experience with current software licensing approaches.

It covers both high-impact, lower-overhead issues and more systemic, structural challenges that affect customers, system integrators, and independent software vendors alike.
