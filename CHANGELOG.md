# Changelog

All notable changes to the Dynamic Software Licensing repository should be documented in this file.

This changelog is used to track the evolution of the DSL recommendation as an IABM initiative, including structural, editorial, and content-related changes.

The format is intentionally lightweight at this stage and is primarily intended to support transparency during drafting and repository organization.

## Change Categories

The following categories should be used where applicable:

### Added

New files, chapters, annexes, schemas, diagrams, or structural elements introduced into the repository.

### Changed

Updates to structure, wording, organization, or chapter design that modify existing content or layout.

### Clarified

Changes that improve interpretation, scope, consistency, or terminology without materially changing intent.

### Removed

Content, files, or structures that have been deleted from the repository.

## [0.1.0] - 2026-03-10

### Added

- Initial repository structure for the Dynamic Software Licensing recommendation
- Main recommendation directory and chapter layout
- Normative and informative annex structure
- Schema and diagram placeholder directories
- Initial root governance and contribution files
- Initial chapter index files for the main recommendation structure

### Changed

- Recommendation chapters reorganized into chapter folders
- Chapter entry files aligned to a `00-index.md` structure
- Main recommendation layout adjusted for clearer GitHub navigation

### Clarified

- Repository purpose as a working draft for the Dynamic Software Licensing initiative
- Editorial positioning as an industry recommendation with standard-like structure
- Separation between main recommendation content and annex material
