# Diagrams

## Purpose

This directory contains diagram assets that support the DSL best-practices draft.

## Current Files

- `DSL Event Based Production.svg` supports the event-driven production profile.
- `aws-reference-architecture/` contains the AWS reference architecture PNG diagrams used by
 Annex F.

## Guidance

- Diagram files are informative support material.
- The normative meaning remains in the Markdown chapters and annexes.
- When a diagram and the text diverge, the Markdown text takes precedence until both are
 reconciled.
